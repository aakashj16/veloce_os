# Security policy

Veloce OS is in the planning stage. The project currently has no supported Veloce releases.

## Reporting a vulnerability

Use the repository's [Security tab](https://github.com/aakashj16/veloce_os/security) and choose **Report a vulnerability** if private vulnerability reporting is available. If it is unavailable, use an existing private contact channel for the maintainer. Keep vulnerability details out of public issues, pull requests and discussions. Enabling and verifying the private reporting path is a maintainer task before distributing a public image.

Include the affected commit or build, package versions, impact, and minimal reproduction steps. Remove credentials, personal data and private logs. For an issue isolated to an upstream component, use that project's security process.

## Release safeguards

Use trusted package sources, preserve upstream security updates, and track the provenance of release images and bundled packages. The maintainer reviews update and recovery evidence, third-party notices, and applicable distribution terms before releasing an image. The [requirements register](docs/requirements.md) tracks the security and release gates.
